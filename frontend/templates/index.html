    📋 测试用例模板说明

    点击「下载模板」获取 JSON 文件，按以下格式填写后上传。

    字段说明示例值
    id唯一标识custom_001
    dimension评测维度multimodal_intent / end_to_end / custom_agent / security_risk
    title用例标题【多模态感知】语音指令解析
    description详细描述用户说：导航到最近的加油站
    input_data输入数据（对象）{"text": "导航到最近的加油站"}
    expected_output期望输出（对象）{"intent": "navigation"}
    difficulty难度等级easy / medium / hard
    source来源custom
    上传格式支持：
    📄 单个用例：JSON 对象 📁 批量上传：JSON 数组 [{...}, {...}] 📊 CSV 格式（需包含表头）
    💡 小提示：CSV 格式请确保包含 id, dimension, title, description, input_data, expected_output, difficulty, source 列。input_data 和 expected_output 列建议存 JSON 字符串。
